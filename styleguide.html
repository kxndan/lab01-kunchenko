2. Компоненти інтерфейсу

Кнопка (.btn)

Призначення: Елемент для виклику дії користувача або переходу за сценарієм.

Головна дія (.btn--primary) Другорядна дія (.btn--outline) 
<a href="#" class="btn btn--primary">Почати навчання →</a>
<a href="#" class="btn btn--outline">Про напрям</a>

Вимоги доступності: Для дій брати <button>, для переходу <a href>. Мінімальний розмір 44×44px для сенсорних екранів (WCAG 2.5.5).

Коли НЕ застосовувати: Не використовувати для звичайних навігаційних посилань у списку меню (там використовуються прості <a>).

Картка (.card)

Призначення: Контейнер для візуального відокремлення та групування пов'язаної інформації за гештальт-принципом спільної області.

Звичайна картка

Вміст картки з відступами системи.

Акцентна картка

Для важливих блоків або сайдбарів.

<section class="card">...</section>
<section class="card card--accent">...</section>

Коли НЕ застосовувати: Не загортати дрібні однорядкові написи; картка призначена для цілісних інформаційних вузлів.

Поле форми з підписом

Призначення: Збір текстових даних користувача із вбудованою доступністю.

<label for="email">Електронна пошта</label>
<input type="email" id="email" required>

Вимоги доступності: Зв'язок for + id обов'язковий. Підпис ніколи не замінюється атрибутом placeholder.
