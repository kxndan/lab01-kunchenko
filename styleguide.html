2. Компоненти інтерфейсу

Кнопка (.btn)

Призначення: Елемент для виклику головної чи другорядної дії користувача.

Головна дія (.btn--primary) Другорядна дія (.btn--outline) 
<a href="pages/resources.html" class="btn btn--primary">Почати навчання →</a>
<a href="about.html" class="btn btn--outline">Про напрям</a>

Вимоги доступності: Для дій брати <button>, для переходів — <a href>. Мінімальна область натискання 44×44px за WCAG 2.5.5.

Коли НЕ застосовувати: Не використовувати клас .btn для пунктів верхнього навігаційного меню.

Картка (.card)

Призначення: Контейнер для візуального групування пов'язаної інформації за гештальт-принципом спільної області.

Звичайна картка

Стандартний інформаційний блок на світлому фоні з лівою акцентною смугою.

Акцентна картка

Блок із градієнтом для важливих повідомлень або сайдбару сторінки.

<section class="card">...</section>
<aside class="card card--accent">...</aside>

Коли НЕ застосовувати: Не загортати короткі однорядкові написи або поодинокі посилання.

Поле форми з підписом

Призначення: Збір даних від користувача із забезпеченням повної доступності для скрінрідерів.

<label for="email">Електронна пошта</label>
<input type="email" id="email" required>

Вимоги доступності: Зв'язок for + id обов'язковий. Підпис ніколи не замінюється атрибутом placeholder (критерій WCAG F94).
