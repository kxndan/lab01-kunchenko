## 1. Призначення сайту
Освітній статичний ресурс, розроблений для студентів спеціальності «Комп'ютерні науки». Портал надає структуровану інформацію про класичні алгоритми сортування, структури даних та асимптотичний аналіз Big O.

## 2. Спосіб запуску
* **Локально:** відкрити кореневий каталог у Visual Studio Code та запустити файл `index.html` через розширення **Live Server**.
* **Онлайн:** відкрити пряме посилання на GitHub Pages (HTTPS).

## 3. Структура каталогів
```text
lab01-kunchenko/
├── css/style.css          # Єдина таблиця стилів на токенах
├── fonts/                 # Локальні шрифти WOFF2 (Inter)
├── img/                   # Оптимізовані WebP та JPG ілюстрації
├── pages/resources.html   # Сторінка додаткових ресурсів
├── video/                 # Відеоматеріали з доріжкою субтитрів VTT
├── 404.html               # Кастомна сторінка помилки
├── privacy.html           # Політика конфіденційності (GDPR)
├── robots.txt             # Інструкції для пошукових роботів
├── sitemap.xml            # XML-карта сайту
├── styleguide.html        # Живий довідник дизайн-системи
└── index.html             # Головна сторінка
